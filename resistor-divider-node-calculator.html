Node targets

Node voltage is treated as fixed and exact — e.g. a chip's internal reference (1.2 V, 0.8 V, etc.) that doesn't move regardless of resistor tolerance. Desired Vin is what you'd like the top rail to be; since real resistors only land near the ideal ratio, the actual Vin needed to hold that node exactly at its fixed voltage will be slightly off — the results table shows that actual required Vin for each combination, ranked by how close it lands to your desired Vin.

Top combinations

Node voltage is treated as fixed and exact (e.g. a reference pin). Vin1, Vin2, etc. are the actual top-rail voltage this combination would need in order to hold each node exactly at its fixed voltage — R1 is the resistor nearest the input, nodes are numbered top to bottom. Accuracy = 100% minus the worst-case error across nodes, expressed as a percentage of that node's desired Vin. E48/E96/E192 values are generated from the IEC 60063 geometric formula, rounded to 3 significant figures. The solver samples the resistance window on a log scale and evaluates nearby preferred-value candidates at each point rather than an exhaustive search, so it may occasionally miss an equally good combination in an extremely narrow window.
